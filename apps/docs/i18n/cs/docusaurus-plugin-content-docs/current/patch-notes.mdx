# Poznámky k verzím

Achordeon se aktualizuje na pozadí a dá vám vědět, když čeká nová verze - tahle
stránka říká, do čeho byste se načítali.

## 4. 8. 2026

- **Transponování při vystoupení** - zahrajte píseň v jiné tónině, aniž byste ji
  změnili. V nabídce při vystoupení přibyl řádek **Transponovat**, na počítači je
  ovládání rovnou v liště. Publikum má vlastní, takže divák s kapodastrem není
  odkázaný na to, co zrovna hraje vystupující. [Transponování](/stage-audience/index.mdx#transponování)
