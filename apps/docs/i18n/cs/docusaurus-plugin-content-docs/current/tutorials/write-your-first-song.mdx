# Napiš svou první písničku

Od prázdné písničky k přehlednému akordovému zápisu. V aplikaci začneš
v <AppLink to="songs">`Songs`</AppLink>:
vytvoř písničku a pojmenuj ji. Všechno níže je zápis, který pak píšeš — projdi si
to tady a náhled vpravo je vlastní náhled aplikace.
