# Print a songbook

The book as paper: cover, contents, numbers, PDF.

## 1. Open the songbook's settings

## 2. Switch on the title page

## 3. Fill in the title, subtitle and author

## 4. Pick a title page style

## 5. Switch on the summary

## 6. Choose which side the page number sits on

## 7. Switch on page numbers and place them

## 8. Check the preview

## 9. Press Download

## 10. Choose the format

## 11. Set the paper size, orientation and margin

## 12. Save the file
