# Add a font

The face your songs are printed in, kept on the device.

Whichever of the three ways you use, the file is fetched once and stored on this
device, and every render after that — the screen, the preview, the PDF — reads
it from there.

## 1. Open `Settings` ▸ `Font library`

The library is the last section but one of <AppLink to="settings">Settings</AppLink>,
under <Ui id="settings.fontLibrary" />. It is the only place the fonts on this
device are listed in full; the pickers in the render settings offer the same
families, but reading what a font is short of, and deleting one, are page-sized
questions.

The four Achordeon ships with are folded away behind a line saying how many they
are, so the list has a fixed top edge and the fonts you add yourself grow
downwards from it. Open the line and each family is drawn **in its own letters**,
with what it has under it: Roboto Mono has all four styles, Crimson Text, Oswald
and Caveat have two.

The sentence under the heading is worth reading once: a font you add **stays on
this device**. It travels in a backup, because a backup is your whole library,
and it does not travel in an [export](/export-import/index.mdx) — that file
names the fonts your songs are set in so the person opening it knows what to
install, and never carries the font itself.

## 2. Press Add a font

The button at the foot of the list is <Ui id="fonts.add" />. The same dialog is
the last option in **every** font picker in the app, so a font you decide you
want while setting a song can be added without leaving the song.

Its first line is the whole tutorial in one sentence: TrueType only, one file is
one style, and a style you do not add is borrowed from another font. Under it are
three ways in — <Ui id="addFont.search" />, <Ui id="addFont.file" /> and <Ui id="addFont.link" /> —
separated by rules rather than by the word "or", because they are three routes
to the same place and not three steps.

<Image

  src="/img/screenshot-add-font-dialog.png"
  srcDark="/img/screenshot-add-font-dialog-dark.png"

/>

Each of the three commits on its own — a result is its own button, a chosen file
is added the moment you choose it, and the link has <Ui id="addFont.fetch" />
beside it. That is why the footer holds only <Ui id="addFont.close" />: there is
nothing pending for an OK button to confirm. While something is being fetched the
three ways are replaced by <Ui id="addFont.fetching" />, and a font that arrives
closes the dialog — the confirmation is the row now sitting in the list behind it.

## 3. Search Google Fonts by name

Type into <Ui id="addFont.search" />, which reads <Ui id="addFont.searchPlaceholder" />.
There is no Search button and no waiting — the app carries its own index of the
whole Google Fonts catalogue, so the list narrows as you type. A name nothing
matches is answered at once, and answered plainly: <Ui id="addFont.noResults" />

## 4. Or add a `.ttf` file, or a link

<Ui id="addFont.file" /> takes a file off this machine, and it is the path that
needs no network, no catalogue and no explanation. Its submit is the picker
itself: the font is added the moment you choose one, with nothing else to press.

TrueType only.

<Ui id="addFont.link" /> takes two shapes of address:

- The **embed link** Google Fonts hands you, the one meant for a web page's
  `<head>`.
- A **direct `.ttf` address** on jsDelivr or raw.githubusercontent.com.

Press <Ui id="addFont.fetch" />. Anything refused says so under the way that
earned it, beside the field you would fix.

## 5. Add the bold and the italic as their own files

A song asks for four styles: regular, bold, italic and bold italic. A `.ttf`
file holds **one**. So adding a font from a file, or from a direct link, adds
one style, and the bold is a second file added the same way — dropping
`Lora-Bold.ttf` in after `Lora-Regular.ttf` does not make a second family, it
fills the second slot of the one you already have, and the row's count of styles
goes up by one.

Searching is the exception, and the reason to prefer it: a result adds every
static file the family ships in one press, which for most families is all four.

A style you have not added is borrowed from another font, and the
[font library](/settings-account/settings.mdx#font-library) says which.

## 6. Set a song, or a whole songbook, in the font

A font in the library is not yet a font in use. The pickers are the same three
rows in whichever scope you open them:

- **One song** — the gear in the editor, <Ui id="editor.settings" />. That is
  [Fit a song on one page](./fit-a-song-on-one-page.mdx).
- **A whole songbook** — <Ui id="songbooks.settings" /> carries the fonts among
  the few settings that make a house style, so a book can be set in one press.
  See [Build a songbook](./build-a-songbook.mdx#13-restyle-the-chords-for-the-whole-book).
- **Everything** — <Ui id="nav.settings" /> ▸ <Ui id="settings.rendering" /> is
  the base every song starts from.

## 7. Remove a font

Only the fonts you added can be removed — the built-in four have no delete
button. Press the bin on the row and Achordeon answers <Ui id="fonts.removeTitle" />
with the one thing you actually need to decide on: **how many of your songs and
songbooks are set in it**.

render, and take back out again with nothing lost but the download.
