# Tutorials

Each tutorial is one task, done from start to finish. Every one of them is done
in the app, so <AppLink>open it in another tab</AppLink> and work along.

## Get started

- [Set up a device](./set-up-a-device.mdx) — install the app, sign in, back up, sync.

## Create a song

- [Write your first song](./write-your-first-song.mdx) — lyrics, blocks, labels and chords.
- [Fit a song on one page](./fit-a-song-on-one-page.mdx) — render settings until the song stops scrolling.
- [Transpose a song](./transpose-a-song.mdx) — in the editor for good, or on the screen while you play.
- [Add a font](./add-a-font.mdx) — Google Fonts, a file, or a link.

## Build your set

- [Build a songbook](./build-a-songbook.mdx) — put songs in order and keep them there.
- [Print a songbook](./print-a-songbook.mdx) — title page, summary, page numbers, PDF.

## Perform

- [Perform from a songbook](./perform-from-a-songbook.mdx) — stage mode, one song per screen.
- [Play to an audience](./play-to-an-audience.mdx) — a lobby, a PIN, phones that follow along.

## Share

- [Share and import songs](./share-a-song.mdx) — a link or a file, and what the other side does with it.
