# Tips

## A fake label

A real label needs a colon, and it indents the block to make room for the gutter.
When you only want a heading — a marker over a run of chords — bold the heading with
its colon inside the asterisks and put the chords inline: it reads like a label
without becoming one, so the rest of the song does not move.

**Guitar solo:** [[Am F G Am]] [[F G C]]
`}
