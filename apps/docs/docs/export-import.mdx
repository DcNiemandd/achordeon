# Export & Import

There are two ways to export songs from this app:

- **Export**: format for computers, for moving data from one computer to another
- **Download**: format for players, for playing, printing, sharing

Both live behind the same **Download** button. You pick which one you want in the dialog it opens, so you do not have to decide before you can see the choices.

## Export

Exporting is generates JSON file, where will be everything you selected. It's a small database of songs and songbooks. The file is easily editable in a text editor of your choice.

You can find it in `Songs` and `Songbooks` wherever there is a Download button, as the **Achordeon file** option. You just need to select some items.

The first line of the file says where the app that wrote it lives: `"app": "https://achordeon.eu/app/"`. The app itself never reads that line - it is there for whoever finds the file a year later and wonders what opens it.

### ChordPro file

The same dialog also offers a **ChordPro file** (`.cho`). ChordPro is the plain text format most other chord apps read, so this is the way to take your songs to one of them. It holds the words and chords of every selected song, one after another. From a songbook's Download dialog it holds the songbook's songs, in the songbook's order.

It is not a full copy. Songbooks and favourites stay behind. The song's name and its settings are written as `{x_achordeon_...}` lines, which other apps skip and Achordeon reads back, so a ChordPro file imported here keeps them.

## Download

Downloading is little bit more complicated. The basics are:

- download song(s): selected songs in a desired format, the songs will have aspect ratio from its setting or from global settings
- [download songbook](/songbooks/index.mdx): selected songbook in a PDF format, the page size will be custom or A4 by default and the songs will keep their aspect ratio, but will be scaled to fit on the page

A single song can be downloaded as a PDF or an image (PNG). Multiple songs can be a ZIP of images, ZIP of PDFs, or a single multi-page PDF. A songbook is a PDF or a ZIP of images, one per song.

The PDF is vector: its text stays text, so it can be selected, searched and printed at any size without going fuzzy. The fonts are embedded in the file, so it looks the same on a machine that does not have them.

To move or safeguard your **whole** library at once, rather than a selection, use [Backup](/settings.mdx#backup) in Settings.

## Import

You can import all exported and downloaded files. The downloaded files has metadata that is the same as the exported files. This metadata can be lost if you edit the files.

The metadata rides in the **PNG**, one file that is both the picture and the song. A PDF carries none, so import a PDF's song from the Export JSON or from the image.

The rules of importing are as follows:

- Importing songbook will always create new songbook, even if the names are the same.
- Importing songs will give user options to replace, ignore, or create new. You can also import all songs as new with date tag as a prefix

There are three ways in, and all three end at the same preview:

- the **Import** button in Songs or Songbooks, which opens the Import dialog with a row for each kind of file: an **Achordeon file**, or a **Chord sheet**
- a file **dropped anywhere on the page**, several at once being offered one after another
- a **link**, which opens the preview already filled in

The Achordeon file is written as `.achordeon` now. Files already exported as `.json` still import, and the picker accepts both.

## Chord sheets

A chord sheet is a song written outside Achordeon. Achordeon reads two kinds:

- **ChordPro**: `{title: ...}` lines and the chords inline, `[C]`, the format most chord apps write
- **chord rows**: each row of chords sitting above the words it belongs to, the way most chord websites and text files show a song

Either kind is turned into Achordeon [markup](/songs/syntax.mdx) as it comes in. Text with chords in neither shape is not a chord sheet, and comes in as written.

The chords always end up with English names. A sheet written with German names is recognised by an `H` or a `mi` among its chords, and rewritten: `H` becomes `B`, `B` becomes `Bb`, `Fis` becomes `F#`, `Ami` becomes `Am`. If you want the page to print German names, set the chord notation in [Rendering](/settings.mdx#rendering).

A chord sheet comes in three ways:

- **a file**: in the Import dialog choose **Chord sheet** and pick `.cho`, `.chordpro`, `.crd`, `.pro` or `.txt` files. They go through the same import preview as an Achordeon file
- **a paste**: paste the sheet into the editor. If it looks like a chord sheet, a bar over the text offers **Convert**. Convert is one undo step, so Undo brings the paste back. **Keep as pasted** leaves it alone, and so does carrying on typing
- **the editor's Convert buttons**: for a sheet that is already in the editor. Convert the selection or the whole song, or only read its chords as German and write them in English

## Song sites

Some websites full of songs can be searched from the app. The button beside **Import** in Songs or Songbooks, a book with a magnifying glass, opens the search. Type the song's name or the artist and press Enter, or paste a link to a song on one of the sites. The results come grouped by site.

Picking a result shows the song as Achordeon will print it, before anything is saved. When the site has more than one version of the song, you can switch between them. **Import** saves it as a new song and opens it in the editor. **Back to search** brings back the same results.

For now the one Song site is [plnyzpevnik.cz](https://plnyzpevnik.cz).

A song is fetched only when you ask for it, one at a time, and nothing is kept on the way. The search needs an internet connection, so offline the button is off. What the site sees of your search is in [Privacy](/privacy.mdx#song-sites).

### Sites that cannot be searched

Some sites refuse to be read by a machine, and Achordeon respects that. Their songs still come in by copy and paste: open the song on the site, select its text, copy it, paste it into a new song in the editor, and press **Convert**. That is the way for supermusic and for [pisnicky-akordy.cz](https://pisnicky-akordy.cz).

## Sharing a song as a link

Alongside the file, the Download dialog offers a **Link**. It is copied to the clipboard, and the song travels inside it, so nothing is uploaded and nothing is fetched when it is opened. Tapping it opens the import preview on any device, installed app or browser tab, online or not.

A long selection will not fit in a link: something along the way cuts it short and it arrives unreadable. When that happens the option is greyed and says so, and the file is the answer instead.

## Writing a song with an AI assistant

The file format is published, so an assistant can write one for you. The schema lives at [achordeon.schema.json](pathname:///achordeon.schema.json). Hand it that and ask for an Achordeon import file.

There is also a ready-made skill, which teaches the markup and carries Achordeon's own parser so the assistant can check its work before handing it over:

- [achordeon-song.zip](pathname:///achordeon-song.zip) - for Claude, which can run the scripts it contains
- [achordeon-song-gpt.zip](pathname:///achordeon-song-gpt.zip) - instructions and knowledge files for a Custom GPT
- [achordeon-song-gem.md](pathname:///achordeon-song-gem.md) - one file to paste into a Gem

How to install each one is in the [AI import guide](/guides/ai-import.mdx).

Whatever writes the file, the import preview tells you before anything is written how many of the songs have markup Achordeon could not make sense of, so a stale skill, or an assistant that never had one, is something you find out about up front rather than on the page.
