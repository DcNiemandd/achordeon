## Profile

The application is fully offline. You don't need to login. But login will give you more functionality depending on you tier:

- **No login**
  - manual synchronization via file download & upload
- **Free**
  - manual synchronization of the profile to the google drive
- **Premium**
  - same as Free tier
  - your files can be automatically synchronized to our servers
  - you can have `Audience`

:::info[Testing]
Audience can be for free tier as well
:::

Application supports only one user in the browser. Everyone can see your data. The login is for synchronization only.

You can manage your login and synchronization in this section:

- Login / logout, and adding a second sign-in method to the same account
- Buttons for Google Drive synchronization
- _Premium:_ switch for real-time synchronization
- Manual sync: back up the whole library to a file, or restore it from one

Sending a few songs to somebody else is a different job. That is
[export & import](/export-import.mdx), and it lives with the songs, because
choosing which songs is the whole act. Settings links there.

:::note[Drive access is asked separately]
Signing in with Google does not hand Achordeon your Drive. That permission is
asked the first time you back up to Google Drive, and it covers only the backup
file itself. See [your account & Google data](/account-data.mdx#google-drive).
:::

## Rendering

The renderer allows you to customize the output. There is global setting and scoped one.

[`Songs`](songs/editing.mdx#renderer) scope. The controls are grouped into **Page**,
**Title** and **Chords**:

- _Page_: scale (custom text size, useful for maximizing the page space), columns (for
  really long songs), aspect ratio, padding (the white border around the song), and where
  a song that doesn't fill the page sits, horizontal and vertical
- _Title_: position (on top of the page or sideways up the side), layout (the subtitle
  stacked under the title or inline beside it), and the font the title and subtitle share
- _Chords_: the same colour, size and notation a songbook can set, here for a single song

A single song can override anything. A songbook only carries the shared few below.

:::note[One song, one page]
The render settings exist to make the content fit one page.
:::

`Songbooks` scope:

- chords color
- chords size
- chord notation - English (C, D, B) or German (H for B natural, B for B♭). It changes how chords are **printed**, but your song is left exactly as you wrote it, so switching back changes nothing else. `[H]` has always been understood as B natural whichever you pick.
- title font - the face the title and subtitle are set in: the song's own font, a serif, a condensed one or a handwritten one. Set it on a songbook and every song in it follows.

## Backup

Save your whole library to a single file, or restore it from one. This is the entire database, not a selection, different from [exporting](/export-import.mdx) a few songs to share. Restoring **replaces** everything you currently have, so it asks you to confirm first.
